HCI Implementation 3 & 4 - Zoo Admin System

Lock System - Lock/unlock individually through toggles or button by clicking on specific enclosure; can lock all in a zone with toggle or all in zoo with button. Lock/Unlock all buttons grayed out when all are already locked/unlocked.
Permission asked before locking/unlocking all. Map shows lock status through border and background colors and lock icon. All enclosures are currently unlocked by default.

Feeding System - Feed individually through buttons on control panel or by clicking on specific enclosure; animals all need to be fed by default. When fed, buttons turn green and block overfeeding, at 15 seconds the buttons turn yellow and give a message to wait if attempt to feed, and red at 30 seconds.
The last fed time is displayed on the map along with a warning if the animal is overdue for feeding. Feed all for zone or entire zoo also options - will only feed those that need to be fed

Sprinkler System - Sprinklers run for 10 seconds after being toggled on then automatically turn off; can also be scheduled for future and will be turned on at the chosen time daily also for 10 seconds
